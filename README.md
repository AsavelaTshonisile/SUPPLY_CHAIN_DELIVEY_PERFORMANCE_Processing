# Supply Chain Delivery Performance Monitoring System

## Project Overview

The Supply Chain Delivery Performance Monitoring System is a Java and Python project that analyses supply chain delivery data to monitor shipping performance, identify delivery delays, and explore patterns across shipping modes, markets, and regions.

Java is used to process and validate the dataset, while Python is used for data analysis and visualisation. The findings help identify delivery performance issues and support data-driven operational decisions.

## Project Objectives

- Measure actual shipping durations against scheduled durations.
- Identify late deliveries and compare performance across shipping modes.
- Analyse delivery trends across markets and regions.
- Validate data quality and identify duplicate records.
- Visualise findings to support better supply chain decisions.

## Technology Stack

- **Java** – Data processing and validation.
- **Python** – Data analysis.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical operations.
- **Matplotlib** – Data visualisation.
- **Jupyter Notebook** – Interactive analysis and charts.
- **Git and GitHub** – Version control and project hosting.

## Dataset

The project uses the **DataCo Supply Chain dataset**, which contains supply chain and order information, including shipping durations, delivery status, shipping modes, markets, regions, and order profitability.

The original dataset contains approximately 180,519 records. It is used to evaluate delivery performance and investigate data quality.

If the original dataset is not included in this repository, obtain an authorised copy separately and place it in the `data/` folder. Update the notebook or Java file path if necessary.
[https://www.kaggle.com/datasets/saicharankomati/dataco-supply-chain-dataset](url)
## How to Run the Project

### 1. Run the Java Component

1. Install a compatible Java Development Kit (JDK).
2. Open the project in IntelliJ IDEA.
3. Ensure the dataset is available at the path expected by the Java application.
4. Run `Main.java`.
5. Confirm that the processed data is exported to `output/processed_orders.csv`.

### 2. Run the Python Analysis

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

3. Open a terminal in the project folder.
4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `notebooks/Supply_Chain_Analysis.ipynb`.
6. Ensure the processed CSV file is available at the path expected by the notebook.
7. Run the notebook cells in order to perform the analysis and generate visualisations.

**Recommended workflow:** Run the Java component first, followed by the Python notebook, because the notebook analyses the processed CSV generated by Java.

## Key Findings

- The dataset contains approximately 180,519 records.
- The recorded delivery status identifies 98,977 records as late deliveries, representing approximately 54.83% of the dataset.
- First Class and Second Class shipping show particularly high recorded late-delivery rates.
- The analysis identified 60 exact duplicate rows for further investigation.
- The correlation between shipping difference and order profit is approximately -0.0054, indicating almost no linear relationship in this dataset.

## Project Outputs

The project produces:

- A processed CSV file for further analysis.
- Delivery performance statistics and data quality checks.
- Charts comparing shipping modes, delivery statuses, markets, and shipping delays against order profit.
- A PDF report documenting the analysis, testing, findings, and recommendations.

## Limitations

The dataset supports analysis of delivery patterns but does not provide enough operational detail to establish the causes of delays. The findings show patterns and associations, not proof of causation.

## Conclusion

This project demonstrates how Java and Python can work together to process, validate, analyse, and visualise supply chain data. It applies programming, data analysis, data quality assessment, and visualisation techniques to identify delivery performance patterns and support informed operational decisions.
